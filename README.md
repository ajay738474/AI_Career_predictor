# 🎯 AI Career Predictor

An end-to-end Machine Learning project that predicts a suitable career role based on a student's academic performance, technical skills, projects, internship experience, communication and problem-solving abilities.

## 🚀 Project Overview

The goal of this project is to explore how Machine Learning can be used to recommend potential career paths from student skill and academic data.

The project includes data preprocessing, feature scaling, multiple classification models, model evaluation and prediction.

## 🧠 Career Roles

The model predicts one of the following career roles:

- 🤖 AI Engineer
- 📊 Data Analyst
- 🧠 ML Engineer

## 📊 Input Features

The model uses features such as:

- CGPA
- Python Skill
- SQL Skill
- Machine Learning Skill
- Projects
- Internship
- Communication Skill
- Problem Solving Skill
- Deep Learning Skill
- Data Analysis Skill

## 🤖 Machine Learning Models

The project explores and compares multiple classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
